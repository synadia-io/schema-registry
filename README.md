# Synadia Schema Registry

Synadia Schema Registry artifacts are distributed as part of [Synadia Platform](https://www.synadia.com/platform) and requires a license to access.

This public repo provides releases on behalf of the artifact which includes release notes and the software bill of materials (SBOM).
